# 🥔 Brotato - Thai Font & Mod Installer (PC)

ตัวติดตั้งฟอนต์ภาษาไทย PUA และระบบแปลภาษาไทยสำหรับเกม **Brotato (PC / Steam)** ติดตั้งง่ายในคลิกเดียว!

---

### 📥 วิธีการติดตั้ง (Installation):
1. ดาวน์โหลดไฟล์ทั้งหมด หรือดาวน์โหลดไฟล์ `.rar` แล้วแตกไฟล์ออกมา
2. ดับเบิ้ลคลิกที่ไฟล์ **`Install_Thai_Font.bat`**
3. โปรแกรมจะค้นหาโฟลเดอร์เกม Steam และติดตั้งฟอนต์ภาษาไทยเข้าตัวเกมให้อัตโนมัติ
4. เปิดเกม **Brotato** บน Steam ➔ ไปที่ **Options ➔ Language ➔ เลือก "ภาษาไทย"**

---

### 🔄 วิธีการถอนการติดตั้ง (Uninstall):
* ดับเบิ้ลคลิกที่ไฟล์ **`Uninstall_Restore_Original.bat`** เพื่อคืนค่าไฟล์เกมดั้งเดิมของ Steam 100%
